# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The product is a PHP framework; its demonstration interface lives inside Slack, rather than a separately designed web application.

## Users

PHP developers building Slack applications.

## Product Purpose

Thunder Bolt brings Bolt JS capabilities to idiomatic PHP through typed handlers, discovery, fluent builders and durable storage adapters. The hello-bolt application demonstrates these capabilities inside Slack.

## Capabilities and Constraints

Experimental and unpublished. PHP 8.5+ and Tempest 3. The namespace and package name are provisional. This is not an official Slack SDK.

## Brand Commitments

The user requested a minimal identity for the Slack demo only: one distinctive accent, one geometric shape, sparse formatting and plain language. Avoid ornamental AI imagery. This identity does not apply to the Thunder Bolt PHP framework.

## Evidence on Hand

README.md describes implemented functionality and its limits. examples/hello-bolt contains the working demonstration. No customer claims or adoption figures are supplied.
