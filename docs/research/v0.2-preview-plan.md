# v0.2.0 preview execution plan

Goal: finish the remaining practical Bolt compatibility gaps and ship a v0.2.0 preview. The baseline is Bolt JS 5.1.0 at the commit recorded in the parity manifest; PHP-specific choices remain explicit.

## Checkpoints

- [x] Typed immutable installation requests: per-install bot/user scopes, workspace hint, server-side metadata; retain `begin()` defaults.
- [x] Durable request/state consumption: multiple browser tabs, expiry, replay, browser mismatch, concurrent callbacks and denial; explain custom store migration.
- [x] Installation success/failure hooks and reusable host-route handling: save before success hooks, no repeated exchange after hook failure, safe responses and redirects.
- [x] HTTP and Socket Mode context factories: typed transport input, verified/authorized enrichment before middleware, failure routing, fresh context per delivery; jobs keep explicit inputs.
- [ ] Typed interaction/form values: text, selections, identifiers, checkboxes/radios, dates/times, files and rich text; preserve existing raw properties and readers.
- [ ] Recorded end-to-end project fixture: installation metadata through interaction/context/form reading to durable job recovery, shared transport semantics, CI.
- [ ] Re-audit and release: update evidence and upgrade notes, independent standards/spec reviews, Linux/macOS CI, publish v0.2.0 GitHub prerelease.

Checkpoint commits record completed work; the goal remains active until all checkpoints pass. No Packagist publication, separate docs site, new demo, adapter expansion or base application framework is included.
