- Fresh production applications passed with local path and disposable Git sources, including installed discovery, OAuth metadata, HTTP/Socket typed interactions, durable lease recovery and Agent View/Stop fixtures.
- Documentation, generated-source, transport, parity and Node tooling checks passed. Mago format, lint and analysis passed their configured error checks; pre-existing nonfatal advisory counts were unchanged.
- [CI run 41888061776](https://github.com/HelgeSverre/slack-bolt-php/actions/runs/41888061776) passed on the exact release commit: Linux and macOS PHP suites, Windows CLI, generated references and Docker deployment.

The existing fresh-project workflow then passed: readiness and failure reporting, generated listeners/jobs, identity verification, equivalent HTTP/Socket interactions, OAuth metadata, abandoned-lease recovery, deduplication, generated Agent View discovery, typed streaming and native Stop. Sanitized local receipts, screenshots and check logs remain in ignored `work/modern-blocks-live/`; no credentials or unrelated workspace screenshots were committed.
